# After 2.0.0

These are candidates for the next feature release (provisionally 2.1.0), not release commitments. The 2.0 records live in docs/dev/2.0: recipe conflicts, battery-array relocation, touching gateway frames and the Haunting/Blasting modules are all in 2.0.0.

Mixing and Mechanical Crafting upgrade modules were dropped: Create's basin recipes need a basin, fluids and heat, and mechanical crafting needs positional grids and a pattern screen, which do not fit a box module.

New recipes and balance require Andrew's sign-off.

## Longer-term exploration

Kinetic capacitor, world generation, combat features, ambient sound/particle work, and further cosmetics. These need concrete use cases and scope before scheduling. They are not prerequisites for any planned release.

## Carry-forward validation

Multiplayer, third-party fonts/resource packs, modded non-bucket fluid containers, and third-party block-moving tools need broader compatibility coverage. Keep these as explicit validation limits rather than claiming they were tested.
