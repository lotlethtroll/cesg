# CESG Art Pass

> Working plan for the visual overhaul. Waves are ordered by technique (each has a one-time setup
> cost) and by value-per-effort. Every texture ships with stable filenames, so hand-made or
> commissioned art can drop-in replace any generated asset later with zero code changes.
>
> **Art direction** (see memory/texture-art-direction): Create hardware (brass gold-tan, copper,
> gunmetal, andesite, rivets/bevels) fused with End "ender" energy (teal-aqua glow). Fluid color
> language: teal-aqua = ender pearl; deep green + iris = Liquid Eye of Ender; lilac = Teleport
> Essence; shulker magenta = shulker accents.
>
> **Workflow**: PIL scripts compose/recolor from vanilla + Create bases (extracted from the game
> jars) → x10 preview contact sheets reviewed in-chat → approved textures land in
> `src/main/resources/assets/cesg/textures/`. Iterate per family, not per file.
